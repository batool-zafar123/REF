Linear System Solver

A straightforward, elegant way to solve systems of linear equations using Gaussian Elimination and Gauss-Jordan Elimination.

$ pip install matrix-solver-ref
Get Started View on GitHub

How It Works

01

Input

Define the number of equations and variables, then enter the coefficients and constants for your system.

02

Row Echelon Form

Converts the matrix into REF by identifying pivots and eliminating entries below them.

03

Normalization

Each pivot is precisely normalized to 1 to simplify the system.

04

Reduced REF

Performs back-substitution to eliminate entries above the pivots, resulting in the final RREF matrix.

Key Features

Automated Calculation

Handles all complex row operations (swapping, elimination, and scaling) automatically under the hood.

Visual Representation

For 2x3 systems, it leverages matplotlib to elegantly plot lines and visually demonstrate intersection points.

Numerical Precision

Implements a strict 1e-9 tolerance check to safeguard against floating-point inaccuracies.

Functions Reference

Simple, intuitive functions designed for beginners. Call any function with your data directly, or call it without arguments to launch a guided terminal prompt.

to_ref(matrix=None, show_steps=False)

Gaussian Elimination Returns list[list]

Transforms any 2D matrix into Row Echelon Form (REF). Identifies pivots column by column, performs row swaps, and eliminates entries beneath each pivot.

Parameters

  • matrix: Nested list or 2D array. If omitted, prompts for dimensions & entries.
  • show_steps: bool (default False). Prints formatted matrices before and after conversion.

Interactive Prompt

  • Prompts for total rows and total columns.
  • Asks for each element individually: Enter entry [r, c]:
import matrix_solver_ref as msr

matrix = [
    [2.0, 1.0, -1.0],
    [-3.0, -1.0, 2.0],
    [-2.0, 1.0, 2.0]
]

# Converts to REF and returns the result as a new list
ref_matrix = msr.to_ref(matrix, show_steps=True)
print(ref_matrix)
import matrix_solver_ref as msr

# Call without arguments to enter matrix interactively:
ref_matrix = msr.to_ref()

to_rref(matrix=None, show_steps=False)

Gauss-Jordan Elimination Returns list[list]

Transforms any matrix into Reduced Row Echelon Form (RREF). Normalizes leading pivot entries to 1 and performs back-substitution to eliminate entries both above and below each pivot.

Parameters

  • matrix: Nested list or 2D array. If omitted, prompts for matrix input.
  • show_steps: bool (default False). Prints matrices at each stage.

Interactive Prompt

  • Asks for matrix dimensions (rows and columns).
  • Prompts for each entry row by row.
import matrix_solver_ref as msr

matrix = [
    [1.0, 2.0],
    [3.0, 4.0]
]

rref_matrix = msr.to_rref(matrix, show_steps=True)
print(rref_matrix)
import matrix_solver_ref as msr

# Guides you through entering rows & columns:
rref_matrix = msr.to_rref()

solve_system(matrix=None, plot=False, show_steps=True)

Linear Equation Solver Returns dict | None

Solves a system of linear equations from an augmented matrix [A | B]. Returns a dictionary of variable values (e.g. {"X1": 1.0, "X2": 2.0}), detects inconsistent or infinite systems, and can automatically plot 2D systems.

Parameters

  • matrix: Augmented matrix where the last column contains constants.
  • plot: bool (default False). Plots lines visually for 2x3 systems.
  • show_steps: bool (default True). Prints formatted steps and results.

Interactive Prompt

  • Asks: How many equations? and How many variables?
  • Explicitly requests coefficients and then constants for each equation.
import matrix_solver_ref as msr

# System: 1x + 2y = 5,  3x + 4y = 11
augmented = [
    [1.0, 2.0, 5.0],
    [3.0, 4.0, 11.0]
]

solution = msr.solve_system(augmented, plot=True)
print(solution)  # {'X1': 1.0, 'X2': 2.0}
import matrix_solver_ref as msr

# Prompts for equations, variables, coefficients, and constants:
solution = msr.solve_system()

is_consistent(matrix=None, verbose=True)

System Analysis Returns bool

Quickly determines whether a system of linear equations is consistent (has at least one unique or infinite solution) or inconsistent (e.g. leads to an impossible row like 0 = 5).

Parameters

  • matrix: Augmented linear system matrix [A | B].
  • verbose: bool (default True). Prints whether the system is consistent.

Interactive Prompt

  • Prompts for number of equations and variables.
  • Collects equation entries and constants.
import matrix_solver_ref as msr

# Inconsistent system: x + 2y = 5, 2x + 4y = 12
system = [
    [1.0, 2.0, 5.0],
    [2.0, 4.0, 12.0]
]

status = msr.is_consistent(system)
print(status)  # False
import matrix_solver_ref as msr

# Interactively check any system:
status = msr.is_consistent()

plot_system(matrix=None)

2D Visualization Matplotlib Plot

Renders an interactive 2D graph of 2 linear equations with 2 variables. Shows line equations, handles vertical lines gracefully, and highlights the exact solution point.

Parameters

  • matrix: 2x3 augmented matrix representing 2 equations and constants.

Interactive Prompt

  • Asks specifically for coefficients of X, Y, and constant for line 1.
  • Asks specifically for coefficients of X, Y, and constant for line 2.
import matrix_solver_ref as msr

matrix_2d = [
    [1.0, 2.0, 5.0],
    [3.0, 4.0, 11.0]
]

msr.plot_system(matrix_2d)
import matrix_solver_ref as msr

# Prompts specifically for 2 lines and plots immediately:
msr.plot_system()

Quick Start

import matrix_solver_ref as msr

# 1. Define augmented matrix [A | B]
system = [
    [1.0, 2.0, 5.0],
    [3.0, 4.0, 11.0]
]

# 2. Solve and plot
solution = msr.solve_system(system, plot=True)
print("Solutions:", solution)
import matrix_solver_ref as msr

# Convert any matrix directly to RREF
rref = msr.to_rref([[1, 2], [3, 4]], show_steps=True)
print(rref)
import matrix_solver_ref as msr

# Launch full interactive wizard
msr.main()
